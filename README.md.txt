# Sistema de Gestión de Turnos — Taller CarUPS

Programa de consola en Python que gestiona la atención de clientes mediante tres estructuras lineales implementadas desde sus nodos: **pila**, **cola** y **lista simplemente enlazada**.

## Estructura de archivos
- `pila.py` — Historial de acciones (estructura Pila, principio LIFO)
- `cola.py` — Cola de turnos en espera (estructura Cola, principio FIFO)
- `lista.py` — Registro permanente de clientes (Lista Enlazada)
- `main.py` — Programa principal con menú interactivo
- `README.md` — Este archivo

## Cómo ejecutar
Asegúrese de tener Python 3 instalado y ejecute desde la terminal:
```bash
python main.py
